# YOLOv11n Object Detection Project

This repository contains an end-to-end implementation of **YOLOv11 Nano (yolov11n)** for object detection, implemented in Google Colab.

## 📌 Project Overview
YOLOv11n is the lightweight, ultra-fast variant of the YOLOv11 model series created by Ultralytics. This project focuses on training and running object detection efficiently with minimal memory usage and high inference speed.

* **Notebook:** [Open in Google Colab](https://colab.research.google.com/drive/1SJMWemyDFX_3R_UCGUMSd6eqYg1sDOYW#scrollTo=3RZUU2XJtelB)
* **Model Used:** YOLOv11n (Nano)

---

## ✨ Features
* **Real-time Performance:** High FPS detection suitable for edge devices.
* **Low Resource Usage:** Runs smoothly on free cloud GPUs like Google Colab T4.
* **Easy Customization:** Easily adaptable for custom dataset training.
